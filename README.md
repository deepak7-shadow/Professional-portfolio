# Deepak — Liquid Chrome Portfolio

A single-page 3D portfolio: one liquid-chrome Three.js sphere that travels through the page, a project index with cursor previews, a skills section that shows where each technology was used, and a quick-jump palette (Ctrl/⌘ + K).

## Run locally
Open `index.html` in a browser, or serve it: `npx serve .`

## Edit your content
All personal info, projects and skills live in the `DATA` and `USE` objects near the bottom of `index.html`.

## Deploy
Import this repository at vercel.com/new. No build step is needed.

## Résumé
The "Download résumé" buttons link to `Deepak_R_Resume.pdf`, which must stay in the same folder as `index.html`. To update your résumé, replace that file.

## Link preview
`og.png` is the image shown when the link is shared on WhatsApp or LinkedIn. It is referenced with the address https://professional-portfolio-dead-code1.vercel.app/ — if your final address is different, update the three `og:` / `twitter:` URLs in `index.html`.
